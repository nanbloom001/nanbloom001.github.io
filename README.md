# Life Archive

Zero-dependency interactive profile archive for [nanbloom001](https://github.com/nanbloom001).

## Local preview

Run this from the repository root:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000/journey-archive/`.

## GitHub Pages release

1. Create a **public** GitHub repository named exactly `nanbloom001.github.io`.
2. Commit these files to the default branch.
3. In GitHub, open **Settings -> Pages** and select **Deploy from a branch**, then select the default branch and `/ (root)`.
4. The archive will publish at `https://nanbloom001.github.io/journey-archive/`.

## Life Archive

The interactive profile component is published at:

```text
https://nanbloom001.github.io/journey-archive/
```

GitHub Profile README files cannot execute JavaScript or embed an interactive iframe. Use the generated light/dark preview images in the profile repository and link them to the Pages URL above.
